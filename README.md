# 카드 드래스 시스템

`card_testporject` Unity 프로젝트입니다.

- Unity 버전: **6000.0.62f1**
- 작업 브랜치: `card-dress-system`
- 실행 씬: `Assets/Scenes/SampleScene.unity`

## 실행 방법

1. 저장소를 복제하고 `card-dress-system` 브랜치로 전환합니다.
2. Unity Hub에서 저장소 폴더를 프로젝트로 추가합니다.
3. Unity **6000.0.62f1**로 열고 패키지 복원과 에셋 임포트가 끝날 때까지 기다립니다.
4. `Assets/Scenes/SampleScene.unity`를 열고 Play를 누릅니다.

## 팀 작업

변경 사항은 작업 브랜치에 커밋하고, 팀 검토 후 Pull Request로 `main`에 반영합니다.
`Assets`의 `.meta` 파일, `Packages`, `ProjectSettings`는 함께 관리하며,
`Library`, `Temp`, `Logs`, `UserSettings` 등 자동 생성 파일은 `.gitignore`로 제외합니다.
